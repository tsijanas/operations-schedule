Grand Schedule

Combined view across every team in this department.

Every team in this department, stacked together, for the week above — click any name or the + to add, replace, or remove someone, exactly like a normal team's Schedule tab. Changes here are the same real data each team sees in their own Schedule tab, not a copy.

Grand Requirement

Combined view across every team in this department.

Set one department-wide total per task, per day — it splits across your teams automatically, proportional to each team's headcount. Matches tasks by name across teams, since each team's tasks aren't formally linked yet. Nothing changes on any team's own Requirement until you click Apply.

Grand Rotation Balance

Combined view across every team in this department.

Rotation balance

How many times each person has worked each task, all time. Each task is only compared across the people actually eligible for it, so an IC3-only task is judged only against IC3s.
